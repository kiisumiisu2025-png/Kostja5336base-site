Kostja5336base — сайт сервера

КАК ОТКРЫТЬ
1. Распакуй ZIP.
2. Открой index.html двойным кликом.

КАК ПОМЕНЯТЬ IP
Открой app.js и измени:
const SERVER_ADDRESS="90.190.173.52:25565";

КАК ДОБАВИТЬ НОВОСТЬ
Открой news.js.
Скопируй один блок новости, вставь его в начало списка и измени дату, тег, заголовок и текст.

ГДЕ МЕНЯТЬ РАНГИ
Открой app.js и найди массив const ranks=[ ... ].

КАК ВЫЛОЖИТЬ
Можно использовать GitHub Pages или Netlify.
Для Netlify достаточно загрузить всю распакованную папку сайта.
Для GitHub Pages — загрузить файлы в корень репозитория и включить Pages.

ВАЖНО
Сейчас на сайте указан адрес 90.190.173.52:25565.
Если внешний IP когда-нибудь поменяется, измени SERVER_ADDRESS в app.js.
